# Slow Thinking Icon Renderer
### WASM • Vulkan (Cross-OS) • WebGPU • WebLLM • 3D Rotation

![icon](assets/slow_thinking_icon.png)

Real-time slow-thinking icon for AI UIs - System 2 reasoning visualization.

Features: Rust → WASM SDF core, Vulkan primary backend (Windows/Linux/Android), MoltenVK → Metal on macOS/iOS, WebGPU fallback via wgpu, 3D rotation 8s Y + 10° X tilt, WebLLM drives sand, WASL 40 security checks.
